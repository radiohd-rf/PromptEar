# v0.14 — Панель результата, живой черновик, экспорт форматов

## Цель
Превратить PromptEar из «перетащил → получил docx» в «one-window tool»:
- правая панель результата в окне приложения (живой черновик Whisper → улучшенный текст);
- экспорт в новые форматы: SRT, VTT, TXT, MD (дополнительно к DOCX);
- «без воды»: чистка слов-паразитов внутри существующего прохода 3 (вариант C — без нового LLM-прохода);
- режим улучшения: авто (по умолчанию) / спросить (кнопка «Улучшить с ИИ»).

## 1. Экспорт форматов
- `config.OUTPUT_FORMATS = ("docx", "txt", "srt", "vtt", "md")`, `DEFAULT_FORMAT = "docx"`.
- `core/models.Segment(start, end, text)` + `TranscriptionResult.segments: list[Segment]`, `duration_sec`.
- `Transcriber.transcribe_with_segments(...) -> (text, segments, duration_sec)`; `transcribe()` остаётся (строка), реализован поверх нового метода.
- `utils/files.py`:
  - `save_srt(path, segments, fallback_text, duration)` — куски `00:00:01,000 --> 00:00:02,500`;
  - `save_vtt(...)` — куски `00:00:01.000 --> 00:00:02.500` + заголовок `WEBVTT`;
  - `save_md` / `save_txt` — текст UTF-8;
  - `save_text_output(path, fmt, text, segments, duration)` — общий диспетчер для SaveStep и endpoint улучшения.
- SRT/VTT строятся из сегментов **сырого** Whisper (таймкоды есть только там). Если сегментов нет — один кусок на весь текст.

## 2. «Без воды» (вариант C)
- Никакого четвёртого прохода. В промпт `_pass_structure` (проход 3) добавляется правило:
  «Удали слова-паразиты и повторы-заполнители (это самое, ну, типа, как бы, вот, значит), не меняя смысл».
- Дату сообщение прохода 3: «Структура (абзацы, диалоги, без воды)».

## 3. Панель результата + стриминг + тумблер
- Раскладка: `main` → CSS-сетка `1fr 1fr`; слева ввод (drop-zone, файлы, контекст, тулбар, лог), справа панель результата.
- Панель: заголовок-бейдж («Черновик (Whisper)» / «Улучшено ИИ»), прогресс «Проход 2/3», скролл-текст, кнопка «Улучшить с ИИ» (режим ask).
- Новые события:
  - `DraftEvent(text, final)` — живой черновик из сегментов (streaming), `final=True` в конце транскрибации;
  - `EnhancingEvent(pass, total)` — прогресс проходов;
  - `ResultEvent(text, filename)` — финальный улучшенный текст (авторежим).
- `PipelineConfig.enhance_mode = "auto" | "ask"`. В режиме `ask` EnhanceStep пропускается, черновик сохраняется, панель показывает кнопку.
- Endpoint `POST /api/enhance/<task_id>/<filename>` — улучшение сохранённого черновика по запросу, перезапись файла, JSON `{text, output_path}`.
- `SaveStep(result_store=...)` кладёт результат в реестр задачи (`task["results"]`) для повторного улучшения.
